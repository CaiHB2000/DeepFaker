 # 动态模态优先蒸馏（Dynamic Modal Priority Distillation, DMPD）技术汇报

  更新时间：2025-10-28

  本文面向当前项目 dynamic_distill 的方法、技术原理、实现细节与迄今实验结果做一份完整、可复用的说明，便于后续论文撰写与复现实验。

  ———

  ## 1. 我们的方法在解决什么问题？

  - 任务场景：多模态虚假信息检测（Text + Image），以微博、Twitter 等数据集为主。
  - 关键痛点：
      - 模态信息质量不均衡：部分样本文本更可靠，部分样本图像更可靠。
      - 传统固定蒸馏与固定融合策略容易把“弱模态的噪声”传播给“强模态”，或在不确定样本上过拟合。
      - 仅用 softmax 置信度选择 teacher 容易失真（过度自信、校准差）。
  - 我们的核心理念：让“更确定”的模态在每个样本上充当 teacher，仅对“更不确定”的模态进行有条件的蒸馏；同时使用可校准的不确定性度量与多重门控，避免“坏老师”影响训练稳定性与泛化。

  ———

  ## 2. 相比对比/基线方法的改进

  - 动态 teacher 选择（逐样本）：不再固定 Text→Vision 或 Vision→Text，而是按不确定性大小自适应选择，降低错误监督的概率。
  - 证据式不确定性而非 softmax 置信度：采用 Dirichlet Evidential Learning（证据学习）估计每个模态的 α 向量与不确定性 u=C/∑α。相较于 softmax 分布，证据不确定性更稳健、更可校准。
  - 多重稳定化策略（均为开关式模块）：
      - 置信差阈值 δ + 不确定性 EMA（动量 0.9）：仅在“明显更可靠”时蒸馏，抑制抖动；
      - 延迟启动蒸馏（按迭代/epoch 百分比）：先学判别与校准，再开蒸馏；
      - 自适应温度 T（随 teacher–student 不确定性差异而变）：teacher 越“明显更稳”，蒸馏越“软”，降低梯度冲击；
      - 置信度门控（top1–top2 概率差 ≥ m）：teacher 自身要足够“分得开”才允许蒸馏；
      - 可选 EMA-teacher：进一步平滑 teacher 信号。
  - 校准友好：证据头引入逐步加权的 KL 先验正则（线性拉升），并可在融合头加入轻微的 label smoothing / 熵正则，实测 ECE/NLL、Brier 指标显著改善。
  - 计算友好：只在通过门控的样本上计算 KL/MSE 蒸馏项，其余样本不做蒸馏，几乎不增加总算力成本。

  ## 3. 技术原理与模型细节

  ### 3.1 编码与表征

  - 文本编码（TextEncoder）：BERT 系列（Weibo: bert-base-chinese；Twitter: bert-base-uncased 或本地等价缓存）→ x_t ∈ R^D。
  - 图像编码（VisionEncoder）：ViT-B/16（google/vit-base-patch16-224-in21k）→ x_v ∈ R^D。
  - 两个头（各模态独立）：
      - 分类头：MLP(D→C) 输出 logits_*
      - 证据头：MLP(D→C) + softplus 输出 evidence_*，得 alpha_* = evidence_* + 1
      - 不确定性：S_* = sum(alpha_*)，u_* = C / S_*（数值越大，不确定性越高）

  ### 3.2 动态蒸馏（逐样本）

  - 选择规则：
      - 若 u_t + δ < u_v：Text 为 teacher，Vision 为 student；
      - 若 u_v + δ < u_t：Vision 为 teacher，Text 为 student；
      - 否则跳过蒸馏（不可靠时不学）。
  - 核心损失（teacher 侧 stop-grad 或用 EMA-teacher）：
      - 主：logits-KL（带温度 T）
      - 辅：特征 MSE（可选；在低维投影上，权重小于等于 0.1，避免硬对齐带来模式坍缩）
  - 稳定化：
      - 延迟启动蒸馏：按 start_fraction 或 warmup_steps 延后；
      - 自适应温度：T = base + k·max(0, u_student − u_teacher)；
      - 置信门控：teacher 的 p_top1 − p_top2 ≥ m 时才蒸馏；
      - 不确定性 EMA：u ← μ·u_prev + (1−μ)·u_now，降低 teacher 抖动。

  ### 3.3 证据学习（Evidential DL）

  - 采用基于 Dirichlet 的证据风险：交叉熵的 Dirichlet 期望 + 对先验的 KL 正则，训练前段逐步拉升 KL 系数（先学判别，再学校准）。
  - 与常规 CE、蒸馏项一起联合优化。

  ### 3.4 融合头（推荐保留）

  - 轻量 cross-attention 与不确定性加权拼接：
      - m = [(1−u_v)·m_v, (1−u_t)·m_t, (u_t+u_v)·m_f] → MLP → logits_fuse
  - 融合分支用 CE 优化，不参与 teacher 选择，但作为最终评测输出。

  ### 3.5 总损失

  L = L_fuse
    + α (L_cls_t + L_cls_v)
    + β (L_evi_t + L_evi_v)
    + γ L_distill

  - 蒸馏项：L_distill = λ_KL·KL + λ_feat·MSE（仅对被选中样本累计）
  - 推荐初值：α=0.5, β=0.3, γ=1.0；T_base=2.0；λ_KL=1.0；λ_feat∈[0,0.1]；δ∈[0.05,0.15]

  ## 4. 训练与实现要点

  - 优化器：AdamW；Weibo 默认 lr=5e-5；cosine scheduler（含 warmup）
  - 冷启动：前 40% epoch 不开蒸馏（或迭代 warmup_steps 后再开）
  - EMA：可选开启 EMA-teacher（ema_decay≈0.997）
  - 设备与数据：
      - HuggingFace 模型/处理器本地加载，避免联网依赖
      - DataLoader 在受限环境用 num_workers=0（避免多进程权限问题）
  - 可视化与进度：
      - 训练脚本支持 --progress（tqdm 单行稳定显示）
      - 产物：summary.json、train/val_metrics.csv、test_predictions.csv

  ## 6. 目前结果（Weibo，多种随机种子）

  - 单次“关闭蒸馏”的基线（γ=0）：
      - runs/weibo_full_20251027-141646/summary.json → test：
          - Acc 0.8915，Macro-F1 0.8910，ECE 0.0877
  - 启用“动态模态优先蒸馏+稳定化”的多种随机种子（5 seeds）：
      - 原始汇总 CSV/JSON：paper_results/tables/weibo_multi_seed_results.csv、paper_results/tables/weibo_multi_seed_summary.json
      - 各 seed（test）：
          - seed0：Acc 0.9147, F1 0.9146, ECE 0.0633
          - seed1：Acc 0.9474, F1 0.9474, ECE 0.0381
          - seed2：Acc 0.9195, F1 0.9193, ECE 0.0603
          - seed3：Acc 0.9174, F1 0.9172, ECE 0.0625
          - seed4：Acc 0.9085, F1 0.9084, ECE 0.0642
      - 多种随机种子均值±方差：
          - Acc 0.9215 ± 0.0135
          - Macro-F1 0.9214 ± 0.0135
          - ECE 0.0577 ± 0.0099
  - 对比改进（与“关闭蒸馏”基线相比，按均值对比）：
      - Acc：+3.00pp（0.9215 − 0.8915）
      - Macro-F1：+3.04pp（0.9214 − 0.8910）
      - ECE：下降 0.030（0.0877 → 0.0577），相对下降约 34%
  - 观察：
      - ECE 明显下降，可靠性更好；在若干种子上 Macro-F1 达 0.947+ 的高位。
      - 动态门控与自适应温度避免了“坏老师”对 student 的负向迁移，验证曲线更稳。

  ## 8. 与文献中常见对照方法的关系

  - 传统双分支多模态（如 CAFE、SAFE、EANN、T-FND 等）：
      - 多采用固定融合或一致性对齐，但对“teacher 质量”与“样本级不确定性”考虑不足；
      - 软标签蒸馏多基于 softmax 置信度，易“过度自信”，校准较差。
  - 我们的差异化：
      - 用 Dirichlet 证据学习替代 softmax 置信，提供“可校准”的不确定性度量；
      - 在“样本级、模态间”动态选择 teacher，并叠加阈值、门控、EMA 与自适应温度，确保“只在 teacher 真正可靠时才学”；
      - 同步优化校准（ECE/NLL/Brier）与分类指标，使得“相同 F1 下的置信度更可用”。

  ## 11. 结论（阶段性）

  引入“基于证据不确定性的动态模态优先蒸馏”后，在 Weibo 上对“关闭蒸馏基线”取得了稳定且显著的改进：Macro-F1 均值 +3.0pp，ECE 约下降 34%，并在多种随机种子下保持一致趋势。方法的核心价值在于“只在 teacher 可靠时才蒸馏”，以低成本提升校准与泛化。随着 Twitter/Fakeddit/图结构版的完成，我们预期能进一步扩大优势并形成完整的论文级证据链。
