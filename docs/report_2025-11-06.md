  ## 2. KDD 倾向的论文与实验特征（结合历年 CFP/论文）

  - 方法维度：新颖性+技术深度+可扩展性+可信与复现性是核心评判维度；KDD 鼓励大规模真实数据上的实证与严谨消融。(kdd.org (https://www.kdd.org/kdd2023/call-for-research-track-papers/index.html?utm_source=openai))
  - 研究范围与偏好：多模态/LLM/鲁棒与可信AI/跨域泛化/可解释性/系统效率等均在 Research Track 范围内。(kdd2026.kdd.org (https://kdd2026.kdd.org/research-track-call-for-papers/?utm_source=openai))
  - 复现与开放：代码/数据/模型开放、有 DOI 的可存档链接（如 Zenodo）可获 Artifact 徽章；在投稿时声明开放承诺对评审正向。(kdd2025.kdd.org (https://kdd2025.kdd.org/call-for-artifact-badging/?utm_source=openai))
  - 形式与规范：8页正文需自含主要贡献与结论，附录承载更多复现实验、证明与伪代码。(kdd2026.kdd.org (https://kdd2026.kdd.org/research-track-call-for-papers/?utm_source=openai))

  ## 3. 我们的方法与当前成果（面向论文撰写要点）

  - 方法定位（DPMD，双向不确定性蒸馏）
      - 核心思想：文本/视觉分支互为教师—学生，基于不确定性与事件可靠度动态触发蒸馏；融合教师匹配（teacher‑match）+ 正类事件门控（positive event gate）+ 事件可靠度筛选（event filter）。
      - 关键实现：dynamic_distill/src/training/trainer.py 中支持事件统计、门控、δ课程、温度调度、正类聚焦等；配置在 dynamic_distill/configs/*.
  - 数据集与可信划分
      - Weibo、WeFEND、Fakeddit：完成官方/权威划分与去重；对 WeFEND 采用事件感知划分避免泄漏；提供脚本与日志。
      - 失败与教训记录：dynamic_distill/experiments/wefend_failed_attempts.md（已持续更新）。
  - 当前最好结果（Test）
      - Weibo：Acc 0.9515 / Macro‑F1 0.9515（不确定融合基线）。
      - WeFEND：我们自制 teacher‑match 方案 Acc 0.9481 / Macro‑F1 0.9222（领先老师≈0.97pt，尚未达 ≥1.5pt 目标）。
      - Fakeddit：Acc 0.8705 / Macro‑F1 0.8705（需在多教师/分层蒸馏下继续提升）。
  - 进展可视化
      - WeFEND 全历次实验准确率折线图（时间轴）：paper_results/figures/wefend_acc_timeline.png（去除文本标注，更简洁）。
  - 关键结论（对症改进）
      - 单纯“加权/温度/δ/软回退”易引入噪声事件，收益受限；teacher‑match + 长程训练稳定但提升上限≈1pt。
      - 瓶颈在于“正类覆盖的安全扩大”，需“分层蒸馏权重 + 软强度引导 + 低可靠事件的弱监督”。

  ## 4. 距离 KDD’26 二轮的差距与达成路径

  - 目标指标（硬性）：
      - WeFEND：在同一测试分布与严格事件划分下，Macro‑F1 ≥ 老师 +1.5pt；多种子（≥3）平均达标，方差可控。
      - Fakeddit：相对我们未蒸馏基线 ≥+1.5pt；强化多模态鲁棒性（缺模态/跨域）。
      - Weibo：迁移 DPMD 策略，维持或小幅提升现有最好分数。
  - 论文必要实验清单（对齐 KDD 评审偏好）
      - 多数据集、跨语种/跨域泛化；严谨划分（事件/用户/话题级），泄漏检测；多种子均值±方差；显著性检验。
      - 消融与诊断：门控/权重/δ/温度/双向蒸馏开关；正类/负类分布与误差类型；校准（ECE）与可靠性图。
      - 代价与可扩展：训练/推理耗时与显存；复杂度分析；大批量与多卡可扩展性。
      - 伦理与复现：数据使用/授权/匿名化；环境与依赖快照；一键复现实验脚本与 DOI。(kdd.org (https://www.kdd.org/kdd2023/call-for-research-track-papers/index.html?utm_source=openai))

  ## 5. 下一阶段技术路线（两条并行）

  - 路线A：事件分层蒸馏（Layered Distillation）
      - 按事件可靠度/学生召回动态分配权重，而非二值门控：高可靠事件—强蒸馏；中可靠—中等权重；低可靠—弱权重或仅一致性正则。
      - 在 Trainer 中加入 per‑event weight 计算与日志（已明确插桩点）。
  - 路线B：辅助教师/伪标签（Aux‑Teacher）
      - 用温度校准或轻量迁移教师给低可靠事件提供弱信号，配合置信差缩放，避免噪声主导。
  - 两路线共同要求
      - 先在 WeFEND 做≥3 seed 迭代，再迁移至 Fakeddit、Weibo；保持统一配置风格与日志。
      - 每轮结束更新“成功/失败库”，可视化时间线增量。

  ## 7. 论文结构（8页正文建议大纲）

  1. 引言：问题、动机与贡献（跨数据集统一蒸馏与可信划分的必要性）。
  2. 相关工作：KDD 已接受的多模态与可解释/新事件/传播证据类研究。(kdd.org (https://www.kdd.org/kdd2018/accepted-papers/view/eann-event-adversarial-neural-networks-for-multi-modal-fake-news-detection?utm_source=openai))
  3. 方法：DPMD 框架、事件分层权重、双向不确定蒸馏、门控与温度/δ策略。
  4. 数据与协议：Weibo/WeFEND/Fakeddit，事件/话题级划分与泄漏防控，评价指标（Acc/F1/ECE等）。
  5. 实验：主表（多数据集/多种子），对比方法与统计显著性；鲁棒性（缺模态/跨域）；效率。
  6. 消融与可解释：各门控/权重/双向蒸馏开关、错误分布与案例；可靠性图。
  7. 伦理与复现：数据合规、局限性与负面影响讨论；Artifact/代码/配置的 DOI 与复现指引。(kdd2025.kdd.org (https://kdd2025.kdd.org/call-for-artifact-badging/?utm_source=openai))
  8. 结论与展望：部署落地/数据扩展/更强教师与 OOD。
