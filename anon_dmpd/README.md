\# Anonymous DMPD Repository (for ARR/ACL submission)

This repository contains anonymized code and configuration files for our ARR/ACL submission on reliability-aware gated distillation for multimodal misinformation detection. It is a **self-contained subset** of the full project, with all author-identifying information and large intermediate artifacts (logs, checkpoints, raw data) removed.

The main goal is to make it easy for reviewers to:

- Inspect the implementation of the distillation framework (teacher–match gate, event-level reliability, calibration-oriented loss).
- Reproduce the core Weibo / WeFEND / MiRAGeNews experiments with reasonable effort.
- Regenerate the tables and figures that appear in the paper.

## 1. Structure

- `dynamic_distill/`
  - Core library for training and evaluating multimodal detectors and students.
  - Contains model definitions (text/vision/fusion teachers, DMPD student), gating and event-reliability logic, and training scripts.
- `scripts/`
  - `gen_tables_from_results.py`: utilities to turn JSON summaries into LaTeX tables and metric macros.
  - `make_necessity_figure.py`, `plot_figures.py`: utilities to regenerate selected figures from saved predictions/summaries.
- `STATUS.md`
  - High-level experiment checklist and status (datasets, baselines, main runs).

All paths in configs and scripts are relative; no absolute paths or user-specific information are included.

## 2. Requirements

- Python 3.9+
- PyTorch (CUDA-enabled, version $\ge$ 2.0 recommended)
- HuggingFace `transformers` and `datasets`
- `torchvision` for vision encoders (e.g., ViT, ResNet)
- Common utilities: `numpy`, `scipy`, `pandas`, `scikit-learn`, `matplotlib`, `seaborn`, `tqdm`, `pyyaml`

We omit a pinned `requirements.txt` to keep the environment flexible; any recent versions of the above libraries should suffice. Reviewers can install dependencies via:

```bash
pip install torch torchvision transformers datasets numpy scipy pandas scikit-learn matplotlib seaborn pyyaml tqdm
```

## 3. Core Experiments

The key experiments in the paper can be reproduced by training a teacher and then a DMPD student on:

- **Weibo** (Chinese multimodal rumor detection, text+image, 2-way)
- **WeFEND** (Chinese WeChat public-account articles, text+image, 2-way)
- **MiRAGeNews** (English synthetic news, cross-generator OOD, 2-way)

Each dataset has a corresponding YAML config under `dynamic_distill/configs/`:

- `weibo_* .yaml` — Weibo baselines and DMPD runs
- `wefend_* .yaml` — WeFEND baselines and DMPD runs
- `miragenews_* .yaml` — MiRAGeNews teacher and student runs

### Example: Training on Weibo

```bash
cd dynamic_distill

# Train a multimodal teacher on Weibo
python -m dynamic_distill.scripts.train_mvp \
  --config configs/weibo_teacher.yaml

# Train a DMPD student from the teacher
python -m dynamic_distill.scripts.train_mvp \
  --config configs/weibo_dynamic_distill.yaml
```

Analogous configs exist for WeFEND and MiRAGeNews (see comments inside each YAML for details). Each run writes a JSON `summary.json` containing test metrics (Acc, Macro-F1, Pos-F1, ECE) and optional prediction files for figure scripts.

## 4. Regenerating Tables and Figures

Once the relevant runs have finished and `summary.json` files are available under a `paper_results/` directory (not included here to keep the repo lightweight), tables and figures can be regenerated by:

```bash
cd scripts

# Generate LaTeX tables and metric macros from JSON summaries
python gen_tables_from_results.py --results_root /path/to/paper_results

# Plot reliability diagrams and gate/event figures
python plot_figures.py --results_root /path/to/paper_results
```

The scripts expect a directory structure of the form:

- `paper_results/weibo_* /summary.json`
- `paper_results/wefend_* /summary.json`
- `paper_results/miragenews_* /summary.json`

as described in the paper and in comments inside the scripts.

## 5. Data Access

To comply with licensing and anonymity constraints, **raw datasets are not included**. We provide preprocessing code and instructions under `dynamic_distill/data_prep/` for:

- Weibo multimodal rumor dataset
- WeFEND WeChat dataset
- MiRAGeNews synthetic news benchmark

Reviewers can obtain the original datasets from their public sources (cited in the paper) and then run the provided preprocessing scripts to obtain the same train/validation/test splits used in our experiments.

## 6. Anonymity

This repository is anonymized for double-blind review:

- No author names, affiliations, or personal URLs are present.
- No absolute file system paths (e.g., `/home/...`) are present.
- No logs, checkpoints, or metadata containing user IDs or hostnames are included.

In the camera-ready version, we will link this repository to a public, non-anonymized Git host with full documentation and additional utilities.
